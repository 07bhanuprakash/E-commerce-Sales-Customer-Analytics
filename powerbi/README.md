# Power BI Dashboard

This folder contains the Power BI dashboard developed for the E-commerce Sales and Customer Analytics project.

## Dashboard Pages

1. Executive Overview
   - Total Revenue
   - Total Orders
   - Total Customers
   - Average Order Value
   - Monthly Revenue Trends
   - Top Product Categories

2. Customer & Product Analysis
   - Customer Retention
   - Repeat Customer Analysis
   - Revenue Contribution
   - Customer Cohort Analysis
   - Product Category Performance

3. Delivery & Review Analysis
   - Average Delivery Time
   - Late Delivery Rate
   - Delivery Time Distribution
   - Customer Review Analysis
   - Review Scores by Delivery Status

## Tools Used

- Microsoft Power BI
- Power Query
- DAX
- Data Modeling

The dashboard uses the Olist e-commerce dataset to explore sales performance, customer behavior, and delivery efficiency.

## Power BI Dashboard

The interactive Power BI dashboard provides insights into sales performance, customer behavior, product performance, and delivery trends.
